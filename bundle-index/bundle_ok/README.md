# Sample Submission Bundle

This is a small, clean example bundle used as a `bundle_index.py` fixture.
It contains one Python module, one JSON data file, and one text note, plus
this README with the reproduction commands below.

```bash
python3 -m unittest test_greeter -v
python3 greeter.py --name Ada
```
