--- 2. what the two patterns accept, measured side by side ---
One input separates them. Both anchors reject a LEADING newline, so
the gap was one-ended: the tail of the value, never the head. That is
why a hand-written list of malformed examples never caught it.

=== $ cat /tmp/xrpl_probe/compare_patterns.py ===
"""Side-by-side: what ^...$ accepts vs what \A...\Z accepts."""
import re

OLD = re.compile(r"^[0-9A-F]{64}$")
NEW = re.compile(r"\A[0-9A-F]{64}\Z")
H = "A" * 64

CASES = [
    ("exactly 64", H),
    ("64 + trailing LF", H + "\n"),
    ("64 + CR LF", H + "\r\n"),
    ("64 + CR", H + "\r"),
    ("64 + space", H + " "),
    ("64 + two LF", H + "\n\n"),
    ("64 + LF + X", H + "\nX"),
    ("leading LF + 64", "\n" + H),
    ("63 hex", "A" * 63),
    ("65 hex", "A" * 65),
]

print("%-22s %-9s %-9s %s" % ("input", "^...$", "\\A...\\Z", "differs"))
differ = 0
for name, value in CASES:
    o = bool(OLD.match(value))
    n = bool(NEW.match(value))
    if o != n:
        differ += 1
    print("%-22s %-9s %-9s %s" % (name, o, n, "<== YES" if o != n else ""))
print()
print("inputs where the two patterns disagree: %d" % differ)
exit=0

--- 4. THE PART THAT MATTERS: reuse detection was bypassed ---
audit() groups payouts by the RAW tx_hash string, so <hash> and
<hash>+LF land in different buckets. Two payouts under two different
task_ids sharing one hash is exactly the REUSED_ACROSS_TASKS case
this tool exists to report. On the PARENT, one appended byte removes
every finding and the report comes back clean. See 4d for exactly how
far the repair goes -- it is narrower than "reuse detection restored".

=== $ cat /tmp/xrpl_probe/mk_dup.py ===
"""Writes the duplicate-hash fixtures: plain, and with one LF appended.

argv: <plain.json> <evaded.json> <roster.json>
"""
import json, sys

H = "9F2BE303A1C4D5E6F708192A3B4C5D6E7F8091A2B3C4D5E6F708192A3B4C5D6E"


def rec(pid, tid, tx):
    return {"payout_id": pid, "task_id": tid, "wallet": "rW", "tx_hash": tx}


plain = [rec("p1", "task_one", H), rec("p2", "task_two", H)]
evaded = [rec("p1", "task_one", H), rec("p2", "task_two", H + "\n")]
for path, data in ((sys.argv[1], plain), (sys.argv[2], evaded)):
    with open(path, "w", encoding="utf-8") as fh:
        json.dump(data, fh)
with open(sys.argv[3], "w", encoding="utf-8") as fh:
    json.dump(["task_one", "task_two"], fh)
print("plain:  p1 and p2 share one hash under two task_ids")
print("evaded: identical, except p2's hash has one LF appended")
exit=0
