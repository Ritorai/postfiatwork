Parent commit: 4cc433950c5b7a4dd5d657efa22e84c4fe5dbbc6

Rebuild with: bash mk_stale_evidence.sh
Volatile on a rebuild: the unittest duration, and the python3
version line on a different interpreter. Everything else is
byte-stable. See mk_stale_evidence.sh for why the steps use the
plain `$ ` form rather than the `=== $ ... ===` record form.

Every edit below is made to a scratch copy that mktemp created
and this script removes. The committed files are read, never
written; the last check re-runs against them to show it.
