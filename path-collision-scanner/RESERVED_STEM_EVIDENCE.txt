# Subject: pathscan.py's WINDOWS_RESERVED_NAME rule, which compared the
# text before a component's first dot against the Windows device names
# WITHOUT removing trailing spaces first.
#
# Windows discards trailing spaces and dots from a name before resolving
# it, so "CON .txt" is not a file called "CON " -- it is the console
# device, and the file cannot be created. The dot half was already
# handled: splitting on the first dot reduces "CON..txt" and "CON. .txt"
# to "CON". The space half was not. So a path Windows refuses outright
# was reported as safe, with exit 0, by the tool whose entire purpose is
# to catch names that break on another filesystem.
#
# Every record below is a real run: a "=== $ command ===" header, the
# verbatim output, and an exit= line. Commands are relative to
# path-collision-scanner/ unless the header says otherwise.
