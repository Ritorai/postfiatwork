A BUG THIS TOOL HAD, FOUND BY RUNNING ITS OWN TESTS
---------------------------------------------------

The first version copied the tree to names differing by 30 characters.
Two tests in test_crosspath.py -- a fixture whose JSON formatting is keyed
on len(cwd) % 3, and one whose exit code is keyed on len(cwd) % 2 --
PASSED AS "identical", because 2 and 3 both divide 30. The runner was
silently blind to exactly the class of defect it exists to find.

Any artefact of the form f(len(path)) % N cancels whenever N divides the
length difference. The difference is now 41, a prime, so every period from
2 to 40 is exposed. test_crosspath.py::TestCopyNames asserts the
difference is prime so the property cannot regress quietly. A period of
exactly 41 or a multiple still cancels; that residual gap is limitation 1
in README.md.
